# ADR-0001: 루팅 중 정지 허용 및 거리 기반 신호

- 날짜: 2026-07-21
- 상태: 승인
- 결정자: 사용자 (프로젝트 오너)
- 배경 문서: Docs/agent-temp/scavenger-impl_v0.0.1_plan.md, Codex 교차 검증 결과

## 배경

구현 계획 v0.0.1의 작업 가정 중 두 가지가 교차 검증에서 설계 결함으로 지적되었다.

1. 자동 전진 가정과 "이동 시 루팅 취소" 규칙이 충돌하여 루팅이 성립하지 않음.
2. 기획 원문의 신호는 탈출지점까지의 위치/거리에 대한 비정형 정보인데,
   구현 계획이 이를 잔여 시간 비율 알림으로 왜곡함.

## 결정

1. 조작 모델: 평상시 자동 전진 + 좌우 입력. 루팅 상호작용 시작 시 플레이어는 정지한다.
   - 루팅 중 전진은 허용하지 않는다.
   - 루팅 중 정지는 허용한다 (루팅 = 정지 상태의 홀드 상호작용).
   - 루팅 취소 조건은 좌우 이동 입력 또는 상호작용 해제.
2. 신호 알림: 거리(위치) 기반으로 구현한다.
   - 구간 내 특정 지점 통과 시 탈출지점까지의 거리를 어림할 수 있는 모호한 신호를 발행.
   - 숨겨진 제한 시간은 유지하되, 시간 값 자체는 알림으로 노출하지 않는다.

## 결과

- 구현 계획 v0.0.2에 반영 (플레이어 상태 정의, SignalEmitter 거리 기반 설계).
- 루팅의 시간 비용이 "정지 시간"으로 명확해져, 고가치 루팅 = 더 긴 정지 = 더 큰 리스크 구조가 성립.
