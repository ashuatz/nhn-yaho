# ADR-0007: 2D 벡터 홀드 이동과 가상 조이스틱

- 날짜: 2026-07-22
- 상태: 승인
- 결정자: 사용자 (프로젝트 오너)
- 관련: ADR-0006 (이동 결정 부분 대체), ADR-0001 (루팅 취소 규칙 유지)

## 배경

ADR-0006의 4방향 토글 이동은 "1회 = 연속 이동, 같은 키 = 정지" 가정으로
구현되었고 해석 확정이 대기 중이었다. 사용자가 토글 방식을 폐기하고
2차원 벡터 입력으로 확정했다.

## 결정

1. 이동: 2D 벡터 홀드 방식. 입력이 있는 동안만 이동한다.
   - 키보드: WASD/화살표 홀드 = 8방향 벡터 (대각 허용, 크기 1 클램프).
   - 가상 조이스틱 (좌하단): 드래그 벡터를 아날로그 크기 그대로 공급.
     데드존(반경 비율) 적용. 토글 D-패드는 제거.
   - 키보드와 조이스틱은 합산 후 크기 1 클램프.
2. 아날로그 크기는 이동속도에 비례한다 (과적 배율과 곱연산).
3. 루팅 취소 = 좌우 입력 (ADR-0001 유지). 홀드 이동에서는 좌우를 잡은 채
   E를 눌러도 루팅이 시작되지 않는다 (시작 즉시 취소 방지).
4. 낙사/바닥 붕괴/틸트 시프트 등 ADR-0006의 나머지 결정은 유지.

## 결과

- PlayerMotor: ToggleDirection 제거, SetMoveInput(Vector2) 도입.
- PlayerController: 프레임마다 키보드+외부(조이스틱) 벡터 합산 공급.
  RequestToggle 제거, SetExternalMoveInput 도입.
- VirtualDPad 삭제, VirtualJoystick 신설 (IMGUI, uGUI 전환은 M5-1).
- 진행 순서 재편 (사용자 지시): M3 -> M4 -> M5(uGUI 전환 포함) -> M2.
