# ADR-0004: 복층 배경, 배경 사전 배치, 다음 스테이지 선노출

- 날짜: 2026-07-21
- 상태: 승인
- 결정자: 사용자 (프로젝트 오너)
- 관련: ADR-0003 (심리스 라운드, PCG 셸)

## 배경

PCG 배경 1차본 확인 후 방향 보강이 결정되었다. 맵은 2층 복층 형식으로 느껴져야 하고,
카메라는 사이드뷰에 더 가깝게 (수치는 사용자가 직접 튜닝), 배경은 손으로 미리 배치할 수
있어야 하며, 다음 스테이지는 항상 확정 노출되어 끊김이 없어야 한다.
캐릭터 이동은 하이퍼캐주얼풍 스텝 연출(스쿼시/스트레치 + 홉)을 요구.
배경 스케일링 레퍼런스로 Unity 공식 brg-shooter(BatchRendererGroup) 데모 참고.

## 결정

1. 복층 배경: 측면 럽블 위에 상부 플랫폼(복도 안쪽 오버행 + 지지 기둥 + 소품)과
   복도를 가로지르는 브릿지를 추가해 2층 구조감을 만든다. 보행은 여전히 y=0 단층.
2. 배경 사전 배치: 에디터 윈도우(Scavenger > Environment Authoring)로 시드 기반
   배경을 씬에 생성해두고 손으로 다듬을 수 있다. EnvironmentAuthoring 마커가
   커버하는 z 범위는 런타임 배경 생성을 스킵한다. 범위 밖은 런타임 PCG가 이어받는다.
3. 다음 스테이지 선노출: 구간 체인을 항상 1개 앞서 생성한다 (룩어헤드).
   라운드 시작 시 현재+다음을 함께 짓고, 전진 선택 시 그 다음을 미리 짓는다.
   선택지 노드에서 앞이 비어 보이는 문제 제거.
4. 스텝 연출: 스텝 진행도 기반 홉(포물선) + 공중 스트레치 + 착지 스쿼시.
   비주얼 자식만 조작, 로직/콜라이더 불변. 수치는 인스펙터 튜닝 지점.
5. 카메라는 매 프레임 포즈 재계산으로 변경 - 플레이 중 인스펙터 튜닝이 즉시 반영된다.
   사이드뷰 수렴 수치는 사용자가 직접 결정 후 코드 기본값에 반영 예정.

## 결과

- 게임플레이 배치(루트/폭탄/선택지/신호)는 여전히 전부 런타임 시드 기반.
  사전 배치는 배경 셸에만 적용된다.
- 룩어헤드로 동시 생존 구간이 최대 3개로 늘어난다 (이전 2개).
- 배경 밀도 상향 시 GameObject 큐브 -> BatchRendererGroup 인스턴싱 전환 검토
  (레퍼런스: https://github.com/Unity-Technologies/brg-shooter).
