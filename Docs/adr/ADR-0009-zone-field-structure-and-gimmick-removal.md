# ADR-0009: 존 단위 필드 구조 전환과 기믹 전면 제거

- 날짜: 2026-07-25
- 상태: 승인
- 결정자: 사용자 (프로젝트 오너)
- 관련: ADR-0006 (붕괴 전선 - 대체됨), ADR-0008 (웹 이식 - 기믹 3종 제거됨),
  ADR-0004 (룩어헤드 - 존 체인으로 계승)
- 기준 문서: Docs/agent-temp/필드_규칙_및_절차_v0.0.1.md,
  Docs/agent-temp/7월_마일스톤_작업_우선순위_v0.0.1.md

## 배경

기획 문서 4종(필드 규칙 및 절차 / 드랍 아이템 / 가방과 무게 / 파밍 아이템 및 포인트)이
작성되고, 마일스톤 문서가 개발 순서를 "필드 -> 드랍 -> 가방 -> 파밍 포인트"로 확정했다.

기존 코드는 문서 없이 선행 구현된 상태였고 문서와 다음이 어긋났다.

- 필드 단위: 80m 세그먼트 x 반폭 5.25 (문서: 블록 1x1 / 존 25 x 7 / 필드 = 스테이지)
- 시간 압박: 연속 전진하는 붕괴 전선 CollapseFront
  (문서: 플레이어 뒤 N칸 기준선 + 정상 -> 제거 예정(흔들림) -> 제거 3상태)
- 진행: depth 무한 + 선택지 노드 (문서: 스테이지 = 존 개수 min/max, 2분 30초 볼륨)
- 기믹 9종이 선행 구현됨 (문서에는 "기믹" 개념만 있고 세부 문서 미작성)

사용자 지시: 문서(필드 규칙 -> 파밍 포인트) 기준으로 재정비하고,
현재 있는 기믹(바닥 무너짐 등)은 빼도 된다.

## 결정

### 1. 필드 구조를 문서 용어대로 재작성 (Field/ 신설)

- ZoneDefinition: 블록 크기 / 존 길이·너비(블록 수) / 스테이지 존 개수 min-max /
  바닥 제거 시작 거리(칸) / 흔들림 시간 / 존 아이템 가치 예산 / 드랍 생성 간격.
  lengthMeters·corridorHalfWidth는 블록 수에서 유도 (배경 생성기 입력 호환).
- FloorRow: 바닥 제거 단위 = 존 너비 x 1블록. 3상태 전이 (문서 3.2 (3)).
- Zone: 행 목록 소유 + 제거 기준선 전달 + 요소 부착(AttachToRow).
- FieldSpawner: 스테이지 진입 시 존 개수 확정, 존 체인 최대 3개 유지
  (직전/현재/다음 - ADR-0004 룩어헤드 계승), 제거 기준선 = 플레이어 z - 제거 거리
  (전진 전용 래칫)를 PlayerMotor.MinZ로 공급해 되돌아가기 차단.

폴더/클래스 이름을 문서 용어(블록/존/필드)와 일치시킨다 - 문서와 코드가 어긋나
같은 개념을 두 이름으로 부르던 비용을 없앤다.

### 2. 붕괴 전선(CollapseFront) 폐기

바닥 제거는 "전선이 훑고 지나간다"가 아니라 "플레이어 위치 기준 뒤쪽 N칸부터
행 단위로 사라진다"로 바뀐다. 흔들림 시간이 마지막 경고 구간을 담당하므로
별도 예고 표시(DangerGrid)가 필요 없다.

### 3. 기믹 9종 전면 제거

폭탄 / 밀기 트랩 / 땅 꺼짐 / 낙하물 / 돌진 적 / 기둥 붕괴 /
바닥 장판 / 미사일 폭격 / 굴러오는 블록 - 전부 삭제.
함께 삭제: DangerGrid(기믹 예고 전용), FloorBreaker(기믹 바닥 파괴),
CheckpointZone(파밍 포인트의 안전지대 역할이 대체), ChoiceNode(선택지 폐기),
SignalEmitter(거리 신호 - 문서에 없음), DepthCurve(기믹 수량 스케일링).

근거: 기믹 세부 문서가 아직 없다. 문서 없이 선행된 9종을 끌고 가면
필드/파밍 재정비의 검증 대상이 흐려진다. 기믹 문서 확정 후 재도입한다.

### 4. 스태미나 제거 (유보)

PlayerStamina는 머지 후 배선/표시가 없는 고아 상태였고 API 불일치로
컴파일도 깨져 있었다. 마일스톤 문서 4.2가 "HP / 스태미나 = 별도 문서 예정",
"아웃 게임 특성(스태미나/체력)은 프로토타입 이후"로 유보했으므로 삭제한다.
HP(PlayerHealth)는 유지 - 낙사/기믹 피해의 수용 지점.

## 유지한 것

- 무게 5단계 페널티 (CarryLoad) - 가방 문서 3장과 이미 일치
- 등급 자동 합성 (RunInventory) - 드랍 문서 3장 (등급 수는 문서 4등급 대비 3단계)
- 자동 획득/흡수 (LootSpot), 제한 시간 150초 (= 2분 30초), HP, 아이소 카메라
- 배경 인스턴싱 + 좌우 비대칭 지형 (ADR-0005 + 카메라측 가림 방지)
- 스테이지 끝 웨이포인트 (ADR-0008): Extract = 탈출, Advance = 다음 스테이지

## 결과

- 3개 어셈블리 컴파일 0 에러 (런타임/에디터/EditMode 테스트)
- 삭제된 시스템의 테스트 2종(DangerGridTests / DepthCurveTests) 제거
- 씬/프리팹은 사용자가 Unity에서 Scavenger > Setup Greybox Scene 재실행 필요
  (SegmentSpawner 컴포넌트가 FieldSpawner로 교체됨)
