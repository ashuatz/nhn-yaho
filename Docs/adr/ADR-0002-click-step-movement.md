# ADR-0002: 클릭 스텝 전진 이동

- 날짜: 2026-07-21
- 상태: 승인
- 결정자: 사용자 (프로젝트 오너)
- 관련: ADR-0001 (루팅 정지/거리 신호), 구현계획 v0.0.2

## 배경

v0.1 그레이박스는 자동 전진 + 좌우 입력 + S 브레이크로 구현되었다.
비주얼 레퍼런스(복셀 던전, 경로 화살표) 공유 후 이동느낌/플레이 느낌 우선 검증으로
방향이 정해졌고, 사용자가 클릭 기반 전진을 결정했다.

## 결정

1. 플레이어는 기본 정지 상태다. 자동 전진을 제거한다.
2. 클릭(마우스 좌클릭 또는 스페이스) 1회 = 한 스텝 전진 (고정 거리, 짧은 트윈).
   - 스텝 중 클릭 1회까지 버퍼링하여 연타가 끊기지 않게 한다.
   - 연타 속도 = 전진 속도. 클릭을 멈추면 그 자리에 선다.
3. 좌우 이동(A/D)은 유지한다. 정지 중과 스텝 중 모두 가능.
4. S 브레이크는 제거한다 (기본이 정지이므로 무의미).
5. ADR-0001의 루팅 규칙은 유지된다.
   - 루팅 중 전진 비허용: Looting 상태에서 클릭은 무시된다.
   - 루팅 취소 조건은 기존대로 좌우 입력 또는 홀드 해제.

## 결과

- 폭탄 회피가 좌우 회피 + 스텝 타이밍(기다렸다 지나가기)의 2축이 된다.
  기다림은 숨김 타이머를 소모하므로 리스크-리워드가 유지된다.
- 시간 압박은 "클릭하지 않으면 아무 일도 일어나지 않지만 타이머는 흐른다"로 표현된다.
- PlayerState.Stopped는 제거 (기본 정지). Advancing = 대기+스텝 이동 포괄.
- 구현계획 v0.0.2 섹션 0.1 조작 모델은 본 ADR로 대체된다.
