# ADR-0006: 4방향 토글 이동, 바닥 붕괴 압박, 틸트 시프트 뷰

- 날짜: 2026-07-22
- 상태: 부분 대체 (이동 결정 1항은 ADR-0007로 대체. 붕괴/낙사/틸트 시프트는 유지)
- 결정자: 사용자 (프로젝트 오너)
- 관련: 기획 정리 v0.0.2, ADR-0002(폐기됨), ADR-0007(이동 대체)

## 배경

기획 메모(v0.0.2)로 이동/압박/뷰 방향이 재정의되었고 사용자가 구현을 지시했다.

## 결정

1. 이동: 4방향 기반 자유 이동, 방향 토글식. 클릭 스텝(ADR-0002)은 폐기.
   - 작업 가정 (확인 대기): 방향키 1회 입력 = 해당 방향 연속 이동 시작,
     같은 키 재입력 = 정지, 다른 방향 키 = 방향 전환. 4방향 배타(동시 대각 없음).
   - 점프는 도입하지 않는다 (키 복잡도).
   - 낙사를 도입한다. 바닥이 없으면 떨어지고, 일정 깊이 이하로 낙하 시 사망.
2. 시간 압박: 뒤에서부터 바닥이 무너지는 방식으로 확정.
   - 붕괴 전선(collapse front)이 플레이어 뒤에서 전진. 지나간 바닥 스트립은
     콜라이더가 꺼지고 가라앉는다 -> 밟을 곳이 없어 낙사 (낙사 도입과 결합).
   - 후퇴 불가의 환경적 전달도 이 장치가 겸한다 (붕괴 전선 뒤로는 이동 클램프).
   - 기존 숨김 타이머의 탈출 잠금 규칙은 제거. RunTimer는 경과 기록용으로 축소.
   - 붕괴 접근은 HUD 경고와 배경 진동(임펄스)으로 인지시킨다.
3. 뷰: 틸트 시프트 방향으로 진행. URP 뎁스 오브 필드(가우시안) 볼륨 +
   카메라 포스트 프로세싱 활성화. 초점 대역/카메라 각도는 사용자가 튜닝.
4. 리소스: 큐브 그레이박스 유지. brg-shooter의 배경 셀 이동 로직(이벤트 반응
   바운스 - 스프링 감쇠)을 EnvironmentRenderer에 이식해 폭발/붕괴에 배경이 반응한다.

## 결과

- PlayerMotor/PlayerController 재작성 (토글 이동, 낙사 판정).
- 보행 바닥이 단일 큐브에서 z 스트립으로 분할 (붕괴 단위).
- CollapseFront가 압박의 단일 소스. 속도는 깊이에 따라 증가 (프리팹 튜닝).
- 스텝 홉 연출은 연속 이동용 워크 밥으로 대체.
