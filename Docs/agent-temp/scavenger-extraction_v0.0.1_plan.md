# 폐지줍기 익스트랙션 게임 - 기획 정리 v0.0.1 (plan)

- 상태: 초안 (사용자 확인 대기)
- 출처: 2026-07-21 브레인스토밍 (이호재, 정지상)
- 브랜치: design/scavenger-roguelike-concept

---

## 1. 컨셉 요약

"폐지 줍는" 테마의 익스트랙션(탈출) 게임. 탈콥라이크(타르코프류) 구조를 캐주얼하게 압축한 형태.

- 플레이어는 직선으로만 전진할 수 있는 길을 따라 이동한다.
- 길 주변의 폐지, 보물상자 등 파밍 요소를 최대한 주워서 탈출하는 것이 코어 목표.
- 깊이 들어갈수록 보상 가치와 위험이 함께 커진다 (리스크-리워드).
- 사망 시 획득한 모든 아이템을 잃는다.

## 2. 코어 메카닉

### 2.1 이동 구조
- 길은 앞으로 직선으로만 진행 가능. 후퇴 없음.
- 구간(지역) 단위로 나뉘며, 구간 사이마다 선택지가 주어진다.

### 2.2 파밍
- 주변에 폐지, 보물상자 등 가치가 다른 파밍 요소가 배치된다.
- 가치가 클수록 상호작용 시간이 길거나 별도 조건이 붙는다.
  - 시간 비용: 고가치 아이템일수록 줍는 데 오래 걸림.
  - 조건 비용: 선행 아이템 필요 등 (섹션 4 아웃게임 연계 참고).

### 2.3 탈출 or 전진 선택
- 구간이 끝날 때마다 "탈출" 또는 "다음 지역으로 전진" 중 선택.
- 전진할수록 더 가치 있는 아이템이 등장.
- 사망 시 모든 아이템 손실 (익스트랙션 장르 핵심 긴장감).

### 2.4 장애물
- 파밍 요소 외에 전진을 방해하는 장애물이 존재.
  - 예: 일정 시간 후 폭발하는 폭탄 (스타크래프트 유즈맵 폭탄피하기 류).
- 깊이 들어갈수록 장애물 회피 난이도 상승. 보상 가치 상승과 짝을 이루는 코어 구조.

### 2.5 시간 제한과 비정형 정보
- 탈출 가능한 시간은 정해져 있으나, 그 끝(제한 시점)은 플레이어에게 공개되지 않는다.
- 구간 길이(탈출지점까지의 거리)도 알 수 없다.
- 대신 특정 구간을 지날 때 현재 위치를 어림할 수 있는 알림을 제공한다.
  - 표현 예: 탈출 지점 신호 감지 등.
- 정보를 완전히 숨기지 않고 비정형적으로 흘려서 긴장감과 판단 여지를 동시에 준다.

### 2.6 라운드 템포
- 선택지 사이 텀은 2~3분 수준의 짧은 라운드로 캐주얼하게 구성.

## 3. 게임 루프

```
[아웃게임 준비] -> [입장] -> (구간 진행: 파밍 + 장애물 회피)
    -> [선택지: 탈출 / 전진]
        -> 탈출: 획득 아이템 확정, 아웃게임 복귀
        -> 전진: 더 깊은 구간 (고가치 + 고난이도)
    -> 사망 시: 전량 손실, 아웃게임 복귀
```

## 4. 아웃게임 (강화/메타 진행) - 제안 단계

정지상 제안. 코어 메카닉과의 연결 고리로 검토.

| 제안 | 내용 | 비고 |
|------|------|------|
| 보물상자 업그레이드 | 상자를 업글(확률)하고 여는(확률) 시스템 | 확률 2중 구조 |
| 위험 정보 구매 | 위험 강도를 사전에 알 수 있게 함 | 정보를 상품화 |
| 시간 기반 위험 | 턴이 지나지 않아도 시간 경과에 따른 위험 존재 | 레퍼런스: 덕코프의 밤 |
| 조건형 탈출구 | 탈출용 아이템을 사전 구매 (예: 택시 탈출) | 아웃게임-인게임 연결 |
| 선행조건형 보상 | 특정 도구가 있어야 열리는 보상 (예: 드라이버로 상자 개봉, 마크 방키 획득) | 파밍에 목적성 부여 |
| 숨겨진 아이템 | 플레이어의 센스로 발견하는 은닉 요소 | 레퍼런스: 커비, 타르코프 루즈루트 |
| 시야 시스템 | 전장의 안개 + 위험구역 조합으로 시야가 게임에 영향 | 도입 여부 자체가 논의 대상 |

## 5. 레퍼런스

- 이스케이프 프롬 타르코프: 익스트랙션 구조, 사망 시 전량 손실, 루즈루트
- 스타크래프트 폭탄피하기 유즈맵: 시한폭발형 장애물
- 덕코프(더 나이트 등): 시간 경과형 위험
- 커비: 숨겨진 요소 발견
- 마인크래프트: 방키류 선행조건 아이템

## 6. 미결 사항 (논의 필요)

1. 시야/전장의 안개 도입 여부 - 게임에 영향을 줄지 말지 미정.
2. 탈출 시간 제한의 구체 규칙 - 라운드 전체 공유인지, 구간별인지.
3. 아웃게임 강화의 범위 - 확률 업글 중심인지, 장비/도구 중심인지.
4. 장애물 유형 목록과 난이도 곡선.
5. 플랫폼/조작 방식 (직선 이동이므로 원버튼 계열 가능성 검토).
6. 세션당 라운드 수와 전체 플레이 타임 목표.

## 7. 원본 브레인스토밍 로그 (보존용)

- [이호재] 폐지줍는 게임(탈콥라이크), 직선으로만 이동. 폐지를 주워 최대한 파밍해서 나가기가 코어 메카닉.
- [이호재] 1) 길은 직선 전진만 가능. 2) 주변 폐지/보물상자는 가치와 상호작용 시간이 다름 (가치가 클수록 긴 시간 또는 조건). 3) 중간중간 탈출 또는 전진 선택, 사망 시 전량 손실, 깊을수록 고가치. 4) 선택지 텀은 2-3분의 짧은 라운드.
- [이호재] 5) 탈출 시간은 정해져 있으나 끝은 알 수 없음. 6) 파밍 요소 외에 전진 방해 장애물 존재 (일정 시간 후 폭발 등). 7) 깊을수록 장애물 난이도와 아이템 가치가 함께 상승. 8) 구간 길이는 알 수 없으나 특정 구간 통과 시 위치를 어림할 수 있는 알림(탈출 신호 감지 등) 제공.
- [정지상] 아웃게임 강화 제안: 보물상자 업글/개봉(확률), 위험강도 정보, 시간 경과 위험(덕코프의 밤), 조건형 탈출구 아이템 구매(택시 탈출), 선행조건형 보상(드라이버로 상자 개봉, 마크 방키), 숨겨진 아이템 발견(커비, 타르코프 루즈루트), 시야 영향 여부(전장의 안개 + 위험구역 조합).
