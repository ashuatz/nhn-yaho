## 0. 완료 상태 (v0.1 그레이박스 기준)

이미 구현되어 동작 중:
4방향 토글 이동 / 낙사 / 바닥 붕괴 압박(타이머 대체) / 틸트 시프트 뷰 /
루팅-인벤토리-스태시 / 폭탄 / 구간 체인+선택지+거리 신호 / 심리스 라운드 /
인스턴싱 배경(중경·원경, 셀 출렁임, 이벤트 임펄스) / 시야 클리어런스 /
프리팹 셋업 / 배경 사전 배치 툴 / EditMode 테스트 27개.

기획 v0.0.2 대비 미구현: 수직 요소, 전방 시야 차단 포그, 가방·무게, 퀵슬롯,
인터랙션 키, HP·회복, 최근 획득 표시, 위험 그리드 표시, 신규 위험 요소,
맵 요소 4분리, 조작계 UI.

## 1. 마일스톤 분할

플레이 느낌 -> 파밍 루프 심화 -> 위험 확장 -> 구조 재편 -> UI 정리 순.
각 슬라이스는 원자 커밋 + 컴파일 검증, 마일스톤 완료 시 Codex 교차 검토.

### M1. 이동/지형 심화 (플레이 느낌 마무리)

| 슬라이스 | 내용 | 완료 기준 |
|----------|------|-----------|
| M1-1 수직 요소 | 올라갈/내려갈 수 있는 요소 (경사로/단차). CC stepOffset + 경사 슬로프를 PCG 길 요소로 배치. 높은 단에 고가치 루트 배치 가능 | 단차를 오르내리며 파밍, 실족 시 낙사 |
| M1-2 전방 시야 차단 | 포그를 연출용에서 정보 차단용으로 강화: 전방 가시거리 제한(포그 밀도/커브 재조정), 룩어헤드 구간이 실루엣만 보이게 | 다음 선택지 노드가 근접 전까지 식별 불가 |

### M2. 파밍 루프 심화 (가방/무게/퀵슬롯)

| 슬라이스 | 내용 | 완료 기준 |
|----------|------|-----------|
| M2-1 무게/가방 | LootDefinition에 무게 추가, RunInventory 무게 합산. 3단계(일반/과적/초과적) -> 이동속도 배율. HUD 무게 상태 표시 | 많이 주울수록 느려지고 붕괴에 쫓기는 선택 압박 성립 |
| M2-2 획득 피드 | 최근 획득 아이템 간략 표시(HUD 피드), 파밍 가능 오브젝트 표시(근접 하이라이트) | 획득/획득 가능 정보가 화면에서 읽힘 |
| M2-3 인터랙션 키 | 잠긴 고가치 루트(requiredItemId 활성화). 키는 스태시 보유 검사로 판정 (아웃게임 구매는 후순위) | 키 없으면 열 수 없는 금고가 등장 |
| M2-4 HP/회복 | HP 도입 (폭탄 즉사 -> 대미지화 검토 포함), 회복 오브젝트 상호작용 | 피해 누적과 회복 판단이 생김 |
| M2-5 퀵슬롯 | 퀵슬롯 등록/사용(회복약 등). 수정은 선택지 노드(안전지대)에서만 | 숫자키로 아이템 사용 |
| M2-6 비상탈출 카드 | 퀵슬롯 사용형 특수 탈출 (선택지 노드 밖에서 즉시 정산, 카드 소모) | 위기 시 카드로 이득 확정 가능 |

### M3. 위험 요소 확장

| 슬라이스 | 내용 | 완료 기준 |
|----------|------|-----------|
| M3-1 위험 그리드 표시 | 위험 범위를 복셀 그리드 셀 이펙트로 표시 (큐비트 방식). 기존 폭탄 폭발 반경부터 적용 | 폭발 범위가 바닥 셀 단위로 명확히 보임 |
| M3-2 땅 꺼짐 | 예고(셀 점멸) 후 바닥 스트립 함몰 (FloorStrip.Sink 재활용). 낙사 연계 | 서 있으면 떨어지는 함정 동작 |
| M3-3 밀기 | 플레이어를 특정 방향으로 밀어내는 트랩 (붕괴/구멍 쪽으로 밀리는 위협) | 밀림 + 낙사/폭탄 조합 위협 성립 |
| M3-4 추격 적 | 단순 추격 1종 (후순위 - 붕괴와 압박 중복이라 재미 검증 후) | 검토 후 결정 |

### M4. 맵 구성 재편 (기획 확정: 4분리)

| 슬라이스 | 내용 | 완료 기준 |
|----------|------|-----------|

| M4-2 라이팅 레이어 | 깊이별 조도 변화(URP Volume 단계), 위험/신호 이펙트 정리 | 깊이 체감 + 시인성 가드 |

## 2. 의존 관계

- M2-1(무게)은 M2-5(퀵슬롯), M2-6(탈출 카드)의 선행.
- M3-1(위험 그리드)은 M3-2/M3-3의 표시 기반이므로 선행.
- M4-1(4분리)은 M3 확장 전에 해도 되고 후에 해도 되나, M3에서 위험 종류가
  늘기 전(M3-1 직후)이 리팩토링 비용 최소 지점 - 기본안: M3-1 후 M4-1 삽입.
- M1은 독립적. 플레이 느낌 우선 원칙에 따라 최우선.

권장 실행 순서: M1-1 -> M1-2 -> M2-1 -> M2-2 -> M3-1 -> M4-1 -> M2-3 -> M2-4
-> M2-5 -> M2-6 -> M3-2 -> M3-3 -> M4-2 -> M5-1 -> (M3-4 결정)

## 3. 보류 항목 (기획 미결)

- 스테미나: 도입 여부 미결 - M2-1 무게-이속 체감 확인 후 판단 권장.
- 세계관 (현대/판타지): 리소스(트랙 B) 착수 전까지 결정 필요.
- 이동 토글 해석: 현재 "1회 = 연속 이동, 같은 키 = 정지" 가정으로 구현됨.
  이동느낌 확인 후 확정.
