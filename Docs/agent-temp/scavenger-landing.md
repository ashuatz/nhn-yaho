## 한눈 요약

- 프로젝트: 폐지줍기 익스트랙션 (탈콥라이크), Unity 6000.3 / URP 그레이박스
- 브랜치: design/scavenger-roguelike-concept
- **2026-07-25 기준으로 기획 문서(정본)에 맞춰 레벨 스택을 재작성했다 (ADR-0009).
  이전 마일스톤 표기(M1~M5)와 기믹 9종은 폐기됨** - 아래 내용이 현재 상태다
- 필드 (Field/): 블록 1x1 / 존 25 x 7 / 필드 = 세그먼트가 끝없이 이어지는 체인.
  **존 N개(6~9 랜덤) + 존 사이 구간(8블록) 반복**. 구간에는 탈출 웨이포인트 1개만
  있고, 밟지 않고 걸어서 통과하면 그것이 다음 스테이지(깊이 +1) - 월드 재생성 없음.
  전방 패딩 2존을 미리 만들어 생성 장면이 화면에 보이지 않게 한다
- 압박: **바닥 제거**뿐이다. 플레이어 뒤 6칸에 기준선이 있고 지나간 행이
  정상 -> 제거 예정(흔들림 1.2s) -> 낙하로 사라진다. 되돌아갈 수 없음(MinZ) +
  제한 시간 2:30. 기믹(장애물)은 전부 제거된 상태 - 기믹 문서 확정 후 재도입
- 파밍 포인트: 존 옆에 붙는 구역 (존당 1~2개, 상단 1번째 / 하단 2번째 / 3번째부터
  랜덤). 안전지대(낙사 없음)이며 출구 소켓이 기준선에 닿으면 통째로 낙하.
  **3층 구조: 상단 +1.0 / 하단 -1.0, 계단으로 오르내린다. 입구(z-)와 출구(z+)가
  나뉘어 앞으로 통과하는 우회로** (계단 시각 + 램프 콜라이더)
- 아이템: 존 예산(가치 합) 안에서 바닥에 배치, 접근하면 자동 수집 (획득 거리는
  플레이어 옵션). 등급은 4단계(일반/희귀/영웅/전설)이고 **아이템 등급이 합성의
  시작 등급**이다 - 같은 (종류, 등급) N개(기본 5, 아이템별 덮어쓰기)가 모이면
  상위 등급으로 자동 합성, 전설에서 정지. 획득 제한 = 무게 초과 + 슬롯 초과.
  무게 5단계 페널티(25/50/75/90%). 가방 컬럼은 BagDefinition(최대 무게/슬롯/전역 N)
- 아이템 오브젝트 (2026-07-26): 파밍 포인트의 오브젝트 스팟마다 상자/항아리
  (일반·희귀·영웅) 더미 프리팹이 1개씩 놓인다. **E 홀드 -> 열림 -> 파밍 아이템 1개**
  (고가치 4종, 합성 N=3). 가방 여유가 없으면 그 자리에 남는다.
  이동/홀드 해제/범위 이탈이면 중단, 오브젝트는 남아 다시 열 수 있다
- 조작: WASD/화살표 홀드 = 2D 벡터 이동 (화면 기준 축), 좌하단 가상 조이스틱,
  E 홀드 = 상호작용, 클릭/스페이스 = 라운드 재개, F1 대시보드
- 대시보드: **UI Toolkit, HUD 문서에 얹혀 있고 기본은 접힘**. 헤더 클릭으로 펼치고
  F1로 숨긴다 (구 IMGUI 대시보드는 제거). 숨김 수치는 여기에만 나온다
- HUD: **UI Toolkit** (Assets/UI/Hud.uxml + Hud.uss, HudDocument 프리팹).
  uGUI HudCanvas는 롤백용으로 파일만 남아 있고 씬에는 배치되지 않는다.
  폰트는 코드가 넣는다 (USS resource()는 해석되지 않아 글자가 안 나온다)
- **플레이 씬은 Assets/Scenes/Greybox.unity**다. SampleScene에는 RunSystems/GameFlow/
  HUD가 없어 런이 시작되지 않는다 - 씬을 혼동하지 말 것
- 카메라: 아이소 고정 (pitch 30 / yaw -45, 초망원 원근). 전진 전용 래칫 +
  후퇴 한계는 화면 하단 에지 지면 교점. **+x = 화면 아래(카메라 쪽) / -x = 화면 위**
- 리소스: 런타임 생성물은 Assets/Materials/Greybox/Common.mat 기반
  (Field/GreyboxPalette). 존 바닥은 타일 프리팹 + 노이즈 조합,
  파밍 포인트/아이템 오브젝트는 프리팹 (Assets/Prefabs/Field/) - 아트 다듬기 대상.
  **필드 프리팹은 트림시트 메시로 구워져 있다** (2026-07-26).
  재생성은 Scavenger > Field Trim Sheet > Rebuild Field Prefabs
- 배경: GPU 인스턴싱 (EnvironmentRenderer). 좌우 비대칭 - 카메라측은 계단식 하강
  (발판 가림 금지), 반대측은 럽블 능선 + 스카이라인. 파밍 포인트 영역은 자동 제외.
  **2026-07-26부터 배경도 트림시트 메시**다 (크기를 셀 2m로 스냅해 크기별 메시를
  인스턴싱. 굽기는 Scavenger > Field Trim Sheet > Bake Background Blocks)
- 에셋 이름은 **용도 기반**이다 (색상 해시 금지, 사용자 지시 2026-07-26).
  예: FarmingPoint_Top_Platform.mat / TrimSheetEnv_06_Midground.mat
- 복도 아래는 **저지대 바닥**(팔레트 8)이 메운다 - 아이소 화면에서 아래가 뚫려 보이던
  문제 (2026-07-26). 하늘은 그라디언트 스카이박스
  (Assets/Materials/Sky/GreyboxSky.mat, 메뉴 Scavenger > Ensure Greybox Sky)
- 그레이박스 밝기는 **Assets/Settings/GreyboxTheme.asset**이 정한다 (코드 색 상수는
  기준색 = 색상/채도). 조절은 메뉴 **Scavenger > Greybox Brightness** ->
  슬라이더로 명도 배수(기본 1.7)를 잡고 "적용"으로 프리팹/배경을 다시 굽는다
- 가방: 슬롯을 끌어 가방 밖에 놓으면 1개를 발밑에 버린다. 등급/몫을 유지한 채
  다시 주울 수 있고, 버린 직후에는 반경을 한 번 벗어나야 회수된다

## 세션 시작 체크리스트

1. git pull (다른 PC에서 푸시했을 수 있음)
2. 푸시 안 된 로컬 커밋 확인: git log origin/design/scavenger-roguelike-concept..HEAD
   - 이 PC가 GitHub 미인증이면 터미널에서 git push 1회 (브라우저 인증)
3. Unity 열고 컴파일 에러 없는지 확인
4. 씬/프리팹이 구버전이거나 missing script가 보이면:
   Scavenger > Setup Greybox Scene (프리팹 수리 + 필드 프리팹 생성 + 배선 포함).
   프리팹만 고치려면 Scavenger > Repair Prefabs.
   파밍 포인트가 평면(단차 없음)으로 보이면 Scavenger > Rebuild Farming Point Prefabs
5. Test Runner (EditMode) 실행 - 55개 (2026-07-25 기준 전부 통과)
6. Unity MCP 브릿지 확인 (Window > MCP For Unity). 끊겨 있으면 에이전트가
   씬 조작/테스트를 직접 못 하고 사용자가 메뉴를 눌러야 한다
