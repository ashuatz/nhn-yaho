## 2. 시스템별 정리

### 2.1 이동
- 4방향 이동, 자유 이동 방식. 이동 방향은 토글식으로 구성.
- 올라갈 수 있는 요소와 내려갈 수 있는 요소 존재 (수직 이동 도입).
- 일부 요소는 파괴하거나 상호작용 가능.
- 검토: 점프 도입 여부, 낙사 도입 여부.

### 2.2 맵 진행
- 플레이어 전방은 포그로 가려짐. 탈출 지점은 사전에 알 수 없음.
- 진행 지점을 추측할 수 있는 표시 필요 (기존 거리 신호 방향과 일치).
- 후퇴 불가. 전진만 가능한 구조.
- 후퇴 불가를 환경으로 전달: 뒤에서부터 바닥이 무너지거나 적이 추격하는 방식 검토.
- 지나온 길은 안전 구역이므로 다시 볼 필요가 적음.

### 2.3 맵 구성 (절차적 구성용 요소 분리)
1. 장식
2. 기능
3. 길
4. 라이팅 및 이펙트

### 2.4 상호작용 및 파밍
- 외부(아웃게임)에서 인터랙션 키를 획득 -> 해당 키로 오브젝트와 상호작용 -> 아이템 획득.
  (v0.0.1의 "선행조건형 보상" 제안이 코어 규칙으로 승격된 형태)
- 파밍 아이템 표시 필요. 최근 획득 아이템을 화면에 간략 표시.
- 파밍에는 가방 필요.

### 2.5 위험 요소 및 전투
- 맵 중간에 위협 요소 배치: 밀기 / 폭발 / 땅 꺼짐 / 바닥 붕괴 / 추격하는 적.
- 위험지역은 복셀 그리드 기준으로 표시하고, 위험 범위를 이펙트로 표시.
- 레퍼런스: 큐비트(Qubit)와 유사한 방식.

### 2.6 아이템 및 인벤토리
- 가방: 파밍에 필요, 무게 시스템과 연결.
- 무게: 이동속도에 영향. 3단계 - 일반 / 과적 / 초과적.
- 퀵슬롯: 아이템 사용은 퀵슬롯으로. 외부에서 가져온 아이템 등록 가능.
  안전지대 또는 체크포인트에서 퀵슬롯 수정 가능.
- 비상탈출 카드: 특수 탈출에 사용. 레퍼런스: 타르코프 맨홀 탈출.

### 2.7 플레이어 상태
- HP: 퀵슬롯 아이템 또는 특정 오브젝트 상호작용으로 회복.
- 스테미나 (검토 중): 걷기/달리기에 사용.
  자유 이동 시 스틱 벡터 크기 75% 초과 = 달리기 방식 검토.

### 2.8 시간 압박
- 원칙: 가만히 있는 플레이에 페널티가 필요하다.
- 검토 중인 방식: 시간 경과 자체를 페널티로 / 뒤에서 바닥 붕괴 / 적 추격.
- 시간 경과가 페널티임을 플레이어가 인지할 수 있는 표현 필요.

### 2.9 UI
- 왼쪽 아래 조작계 표시.
- 최근 획득 아이템 간략 표시, 파밍 아이템 표시.
- 퀵슬롯 표시, 무게 상태 표시.

### 2.10 카메라 및 비주얼
- 틸트 시프트 형태의 뷰 검토. 레퍼런스: BRG Shooter 이미지.
- 세계관: 현대와 판타지 사이에서 검토.

## 3. 검토 사항 (미결)

1. 점프 도입 여부
2. 낙사 도입 여부
3. 스테미나 도입 여부
4. 시간 압박을 플레이어에게 전달하는 방식 (시간 자체 / 바닥 붕괴 / 추격 적)
5. 틸트 시프트 뷰 사용 여부
6. 현대 또는 판타지 세계관 선택

## 4. 기존 결정과의 충돌 및 영향

| 기존 결정 | 새 기획과의 관계 | 처리 |
|-----------|------------------|------|
| ADR-0002 클릭 스텝 전진 | 4방향 자유 이동(토글식)으로 대체됨 | 폐기 예정. 이동 재구현 필요 |
| ADR-0001 루팅 중 정지 | 인터랙션 키 기반 상호작용으로 확장됨. 정지 규칙 유지 여부 재확인 필요 | 부분 유지 검토 |
| ADR-0001 거리 신호 | "진행 지점 추측 표시"와 방향 일치 | 유지 |
| ADR-0003 심리스 라운드 | 후퇴 불가/전진 구조와 양립 | 유지 |
| ADR-0003/0005 배경 PCG + 인스턴싱 | 맵 요소 4분리(장식/기능/길/라이팅)로 재편 필요 | 구조 확장 |
| 숨김 타이머 (구현계획 v0.0.2) | 시간 압박 방식 후보 중 하나로 격하. 전달 표현 필요 | 결정 대기 |
| 스태시 아이템 목록 저장 | 가방/무게/퀵슬롯의 데이터 기반으로 연결 | 유지-확장 |
| 카메라 대각 로우앵글 | 틸트 시프트 뷰 검토와 병행 | 튜닝 계속 |

## 5. 그레이박스 구현 영향 (요약)

- 재작업 대상: PlayerController/PlayerMotor (클릭 스텝 -> 4방향 토글 자유 이동),
  전방 포그(현재 원경 연출용 -> 시야 차단 목적으로 강화), 후퇴 차단 장치.
- 신규 시스템: 가방/무게(이속 3단계), 퀵슬롯, 인터랙션 키, 위험 그리드 표시,
  HP/회복, 최근 획득 아이템 UI.
- 유지: 구간 체인/룩어헤드, 거리 신호, 스태시, 인스턴싱 배경, 프리팹 셋업.
