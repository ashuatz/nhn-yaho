## 5. 문서 미비 사항 (ver02 검토)

* 기준 문서 4종(필드/드랍/가방/파밍)을 실제 구현과 하나씩 대조해 확인한 결과입니다
* 세 종류를 구분해 정리합니다 - 문서에 규칙이 없는 것(5.1), 문서와 구현이 어긋나 문서를 고쳐야 하는 것(5.2), 문서에는 있으나 구현이 없는 것(5.3)

### 5.1 기준 문서에 없는 규칙

(1) 스테이지 인계와 정산 절차 문서가 없습니다

* 탈출 지점(정산)과 다음 스테이지 진행은 이미 동작하는 핵심 루프인데, 기준 문서 4종(필드/드랍/가방/파밍) 어디에도 절차가 없습니다
* 그래서 2장 기능표에도 ver01까지 항목이 없었습니다

    -> 다음 내용을 담은 문서가 필요합니다: 존과 존 사이 구간의 역할, 탈출 지점의 배치 규칙, 밟지 않고 지나갔을 때의 처리(다음 스테이지), 깊이에 따른 밸런스 변화

    -> <span style="color:#2a9d8f">ver03: 구간의 역할 / 탈출과 진행 / 런 종료 조건은 [필드 규칙 및 절차 v0.0.2](./필드_규칙_및_절차_v0.0.2.md) 3.3에 신설했습니다. 깊이에 따른 밸런스 변화(스테이지별 컬럼 분리)는 여전히 미작성입니다</span>

(2) 제한 시간 초과 시의 규칙이 없습니다

* 필드 문서 2.1 (3)에 "스테이지는 2분 30초 볼륨"만 있고, 초과했을 때 무엇이 일어나는지가 없습니다
* 앞쪽 존이 계속 생성되는 구조에서는 제한 시간이 런의 실질적인 종료 조건이 되므로 규칙이 명시되어야 합니다

    -> 현재 구현은 시간 초과 = 런 실패(전량 손실)입니다. 이 처리가 의도인지 확인이 필요합니다

(3) 기믹이 우선순위에 없습니다

* 필드 문서 2.1 (2)는 존 구성 요소로 기믹을 포함하지만, 기믹 문서가 미확정이라 기능표에 기믹 항목이 없습니다
* 문서 확정 전까지는 존 구성이 절반만 정의된 상태입니다

    -> [기믹 시스템 문서](./기믹_시스템_v0.0.1.md) 확정이 존 밸런스(존당 기믹 수치 컬럼)의 선행 조건입니다

(4) 답변 대기 중인 [개발 확인] 항목이 남아 있습니다

* [드랍 아이템 시스템 문서](./드랍_아이템_시스템_v0.0.1.md) 6.2에 "아이템 정렬 기준(플레이어 중심 축) 처리 방식은 개발 협의가 필요합니다"가 그대로 남아 있습니다
* 현재 구현은 접근 시 즉시 획득이라 정렬 단계 자체가 없습니다. 정렬 연출을 넣을지 여부가 획득 연출(아트 3.2 - 3번) 발주 범위를 바꿉니다

### 5.3 문서에 있으나 구현이 없는 항목 <span style="color:#2a9d8f">(데이터 계층 해소)</span>

* 2장 표의 순서만으로는 드러나지 않는, 데이터/컬럼 단위의 공백입니다
* 밸런스 세팅을 시작하려면 이 컬럼들이 먼저 들어가야 하므로 실질 블로커였습니다

| 항목 | 문서 | 상태 |
|------|------|------|
| 아이템 정렬 순서 (Priority) | 드랍 9.1 | <span style="color:#2a9d8f">컬럼 추가</span> (정렬·압축 순서 소비는 가방 정리 기능에서) |
| 1회 / 2회 압축 무게, 압축 시간 | 드랍 9.1 / 가방 7.3 | <span style="color:#2a9d8f">컬럼 추가</span> (단계별 무게 조회 포함. 압축 진행 로직은 기능 작업) |
| 아이템 등장 존 (_1, _2 ...) | 드랍 5.2 (4) / 9.2 | <span style="color:#2a9d8f">적용 완료</span> - 존 순번으로 후보를 걸러 배치 |
| 아이템 획득 거리 | 드랍 9.3 (플레이어 옵션) | <span style="color:#2a9d8f">적용 완료</span> - 플레이어 옵션으로 이전 |
| 합성 필요 개수 (N) | 드랍 3.1 / 9.4 + 파밍 4.2 | <span style="color:#2a9d8f">적용 완료</span> - 전역 기본값 + 아이템별 덮어쓰기 |
| 등급 4단계 (전설) | 드랍 2.2 / 파밍 4.2 | <span style="color:#2a9d8f">적용 완료</span> - 아이템 등급이 합성의 시작 등급이고 전설에서 정지 |
| 슬롯 한도 | 가방 2.1 / 5장 | <span style="color:#2a9d8f">적용 완료</span> - 슬롯 = (종류, 등급) 칸. 초과 시 획득 거부 |
| 자동 획득 on/off | 드랍 7장 / 가방 5장 | <span style="color:#FF4444">미착수</span> - HUD 버튼이 필요한 기능 작업이라 이번 범위 밖 |

* 컬럼 값 자체는 시스템 검증용 임시값입니다. 밸런스 값은 데이터 시트에서 정해 넣어야 합니다

    -> 압축 무게는 원본의 90% / 80%, 압축 시간은 0.35 ~ 1.1초로 임시 세팅했습니다

* 남은 기능 작업 (컬럼은 준비됨)

| 항목 | 필요한 것 |
|------|-----------|
| 가방 정리(무게 압축) | 압축 진행 루프 + 슬롯 인터페이스 (가방 6.2 ~ 6.4) |
| 아이템 버리기 | 슬롯 터치 2단 조작 + 압축 안 된 것 우선 소모 (가방 2.3) |
| 자동 획득 버튼 | HUD 버튼 + 드랍만 차단하는 규칙 (드랍 7장 / 가방 5장) |

### 5.4 우선순위 문서 자체의 보완 항목

| 항목 | 내용 |
|------|------|
| 진행 상태 컬럼 | 2장 표에 상태(완료 / 진행 / 미착수)가 없어, 문서만 보고 남은 일을 알 수 없습니다 |
| 선행 조건 컬럼 | 순서가 곧 의존 관계인 것처럼 읽히지만 실제로는 다릅니다 (5.5 참고) |
| 담당 구분 | 기능/아트 표가 나뉘어 있으나, 아트 리소스가 어느 기능의 선행인지 연결이 없습니다 |
| 데이터 세팅 항목 | 기능/아트만 있고 컬럼(데이터 시트) 작업이 표에 없습니다. 실제로는 5.3이 대부분의 블로커입니다 |

### 5.5 순서와 의존 관계가 어긋나는 지점

* 표의 순서를 그대로 따르면 선행 작업이 뒤에 오는 경우가 있습니다

| 작업 | 표 순서 | 실제 선행 조건 |
|------|---------|----------------|
| 가방 정리(무게 압축) | 2.3 - 4번 | 두 가지가 먼저 필요합니다. (1) 안전지대 판정(파밍 포인트, 2.4 - 1번) - 안전지대 밖에서는 정리를 막아야 합니다. (2) 압축 컬럼(1회/2회 압축 무게, 압축 시간, 정렬 순서 - 5.3) |
| 아이템 버리기 / 무게추 인터페이스 | 2.3 - 3번, 5번 | 슬롯 한도(5.3)와 압축 데이터가 있어야 의미가 생깁니다 |
| 아이템 오브젝트 / 상호작용 / 파밍 아이템 획득 | 2.4 - 6~9번 | 파밍 아이템 종류(4.1의 미완성 항목) + 아이템 그룹 컬럼이 확정되어야 합니다 |
| 파밍 포인트 강조 연출 / 상호작용 모션 | 3.4 - 3~4번 | 파밍 문서 5장(연출 구성)이 확정되어야 합니다 |

* 가방 정리는 파밍 포인트 배치 이후로 내리거나, 안전지대 판정만 먼저 떼어 앞에 두는 것이 안전합니다
