## 2. 기능 개발 우선순위

* 기준 문서 순서에 따라 개발 순서를 정리합니다

### 2.1 필드 규칙 및 절차

* 문서: [필드 규칙 및 절차 문서](./필드_규칙_및_절차_v0.0.1.md)

| 순서 | 기능 | 내용 | 참고 |
|------|------|------|------|
| 1 | 필드 단위 구성 | 블록(1x1) - 존(25x7) - 필드(스테이지) 단위 구조 | 2.1 필드 정의 및 구성 |
| 2 | 존 절차 생성 | 플레이어 앞에 다음 존을 미리 생성, 최대 3개 유지(직전/현재/다음) | 3.1 절차 생성 |
| 3 | 존 제거 | 캐릭터 뒤쪽 바닥을 제거 (정상 - 제거 예정(흔들림) - 제거), 되돌아갈 수 없음 | 3.2 존 제거 시스템 |
| 4 | 스테이지 볼륨 | 제한 시간 2분 30초, 존 개수 랜덤(min/max) | 2.1 (3) 필드 구성 |

### 2.2 드랍 아이템 시스템

* 문서: [드랍 아이템 시스템 문서](./드랍_아이템_시스템_v0.0.1.md)

| 순서 | 기능 | 내용 | 참고 |
|------|------|------|------|
| 1 | 아이템 정의 | 아이템 인덱스/무게/가치/등급 등 데이터 구조 | 2.1 아이템 종류 / 9.1 아이템 정의 컬럼 |
| 2 | 존 내 아이템 생성 | 존 예산(가치 값) 안에서 바닥에 랜덤 배치, 생성 간격 유지 | 5. 존 안의 아이템 생성 |
| 3 | 자동 획득 | 일정 거리 접근 시 흡수, 가방으로 획득 | 6. 아이템 획득 방식 |
| 4 | 등급/자동 합성 | 4등급(일반/희귀/영웅/전설), 같은 등급 N개 모이면 자동 합성 | 2.2 등급 / 3. 아이템 획득 자동 합성 |
| 5 | 자동 획득 모드 | 자동 수집 on/off 버튼 | 7. 아이템 획득 모드 |

### 2.3 가방과 무게 시스템

* 문서: [가방과 무게 시스템 문서](./가방과_무게_시스템_v0.0.1.md)

| 순서 | 기능 | 내용 | 참고 |
|------|------|------|------|
| 1 | 가방/슬롯 | 최대 무게, 슬롯 개수(기본/최대) | 2.1 가방 용량 / 2.2 가방 표시 |
| 2 | 무게 이동 페널티 | 무게 비율 5단계에 따른 이동 속도 감소 | 3. 무게와 이동 패널티 |
| 3 | 아이템 버리기 | 슬롯 터치로 1개씩 버리기 (압축 안 된 것 우선) | 2.3 아이템 버리기 |
| 4 | 가방 정리(무게 압축) | [가방 정리] 버튼으로 압축, 진행/중단/예외 처리 | 6. 가방 정리 시스템 |
| 5 | 무게추 인터페이스 | 슬롯별 압축 정도를 무게추 색으로 표시 | 6.4 인터페이스 세부 규칙 (슬롯) |

### 2.4 파밍 아이템 및 포인트 시스템

* 문서: [파밍 아이템 및 포인트 시스템 문서](./파밍_아이템_및_포인트_시스템_v0.0.1.md)

| 2 | 파밍 포인트 생성 규칙 | 존당 개수(min/max), 간격, 상단/하단 배분(1-상단/2-하단/3+랜덤 50:50) | 2.4 (2) 복수 배치 시 생성 규칙 / 2.5 상단/하단 배분 규칙 |

| 4 | 아이템 오브젝트 | 오브젝트 스팟에 생성(파밍 포인트 등급별 확률), 종류/등급 | 3.1 아이템 오브젝트란 / 3.2 오브젝트 종류 |

| 6 | 파밍 아이템 획득 | 오브젝트 열면 아이템 그룹에서 1개 추첨(합산 확률), 가방 획득 | 3.4 획득 절차 / 3.5 획득 제한 |
| 7 | 파밍 아이템 | 4등급, 합성(N=3), 획득 시 처리(드랍과 동일) | 4. 파밍 아이템 |
