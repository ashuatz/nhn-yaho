## 0. 전제와 작업 가정

프로젝트 현황: Unity 6000.3 / URP (PC + Mobile 렌더러) / Input System 1.19 / 빈 템플릿 상태.
Meshy 에셋 파이프라인 세팅 완료 (브릿지 + MCPForUnity generate_model).

### 0.1 확정 사항 (사용자 결정, ADR-0001 / ADR-0002)

- 조작 모델 (ADR-0002로 개정, 2026-07-21): 기본 정지 + 클릭 1회 = 한 스텝 전진.
  좌우 이동(A/D) 유지, 자동 전진과 S 브레이크 제거. 루팅 중 클릭(전진) 무시.
  - 루팅 취소: 좌우 이동 입력 또는 상호작용 해제 (ADR-0001 유지).
- 신호 알림: 거리(위치) 기반. 구간 내 지점 통과 시 탈출지점까지의 거리를 어림하는 모호한 신호.
  - 숨겨진 제한 시간은 유지하되 시간 값은 알림으로 노출하지 않음.

### 0.2 작업 가정 (프로토타입용 임시 결정)

| 미결 항목 | v0.1 가정 | 근거 |
|-----------|-----------|------|
| 시야/전장의 안개 | 도입하지 않음 | 코어 루프 검증 우선 |
| 탈출 시간 규칙 | 런 전체 단일 숨김 타이머, 매 런 범위 내 랜덤 | 고정값은 반복 플레이 시 암기됨 (검증 지적) |
| 타이머 진행 정책 | 루팅 중, 선택지 노드에서 모두 진행. 일시정지 시에만 정지 | 정지=안전이면 긴장감 소실 |
| 시간 초과 결과 | 탈출 불가(잠금)만. 즉사 아님. 상세 규칙은 플레이 후 조정 | 기획에 없는 규칙이므로 최소 침투 |
| 아웃게임 범위 | 스태시 저장만. 강화/구매 없음. 단, 조건형 아이템 재미는 v0.1에서 검증 불가함을 명시 | 인게임 루프 먼저 |
| 시점 | 쿼터뷰 (탑다운 기울임) | 회피 + 파밍 요소 시인성 |
| 플랫폼 검증 | v0.1은 PC 에디터만. 모바일 입력/성능은 v0.2 이후 리스크 항목 | 범위 제한 |

전체 방침: 과대 시스템 금지, 그레이박스(프리미티브) 우선 진행 후 리소스 트랙에서 교체.

## 2. 트랙 A: 코어메카닉

### 2.1 폴더 구조

```
Assets/Scripts/Game/
  Run/        런 상태 머신, 런 타이머(시간 정책), 정산
  Player/     상태 기반 이동(자동 전진/정지/루팅), 사망 처리
  Loot/       파밍 상호작용, 인벤토리(런 한정), 가치/시간 데이터
  Segment/    구간 생성 체인, 깊이 스케일링, 선택지 노드, 거리 신호
  Obstacle/   시한폭발형 장애물 (폭탄 단일 클래스)
  UI/         루팅 게이지, 가치 합계, 선택지, 알림 배너 (uGUI)
  Debug/      런 상태 대시보드 (온스크린 로그)
```

각 폴더에 CLAUDE.md 작성 (관리 규약 유지).

### 2.2 구현 순서: 수직 슬라이스 (검증 반영, 기능별 순차에서 변경)

한 구간이 돌아가는 최소 루프를 최우선으로 만들고 살을 붙인다.

| 단계 | 내용 | 완료 기준 |
|------|------|-----------|
| S1 | 런 상태 머신 + 디버그 대시보드 | 상태 전이(대기/진행/정산/사망)와 실수치가 화면에 보임 |
| S2 | 구간 1개 + 플레이어 상태 이동 | 자동 전진/좌우/정지 상태가 구간 끝까지 동작 |
| S3 | 루트 1종 (홀드 루팅 + 인벤토리) | 정지-홀드-획득-취소 사이클 동작 |
| S4 | 폭탄 1종 (근접 활성화) | 접근 시 카운트다운, 폭발, 사망, 전량 손실 |
| S5 | 선택지 노드 (탈출/전진) + 구간 체인 | 깊이 증가와 구간 재생성 |
| S6 | 런 타이머 + 거리 신호 | 숨김 타이머 랜덤, 지점 통과 시 거리 신호 발행 |
| S7 | 정산 + 스태시 저장 | 탈출 시 아이템 목록이 스태시 JSON에 누적 |

각 단계 원자 커밋 + /unity-cs-compile-check. S7 완료 시 /codex 교차 검토.

### 2.3 핵심 설계 (검증 반영 사항 포함)

플레이어 상태 (ADR-0001):
- `Advancing` (자동 전진 + 좌우) / `Stopped` / `Looting` (정지 고정, 홀드 진행) / `AtChoice` / `Dead`
- 루팅 중 전진 입력 무시, 좌우 입력은 루팅 취소로 처리.

런 규칙:
- `RunStateMachine`과 `RunTimer` 분리 (RunController 비대화 방지).
- 타이머: 범위 랜덤 (예: 150-210초, 데이터화). 루팅/선택지 중에도 진행.
- 시간 초과: 탈출 노드 잠금. 사망 아님.

거리 신호:
- `SignalEmitter` (구간 배치물): 통과 시 다음 탈출 노드까지의 거리 구간(가까움/중간/멂)을
  모호한 문구로 발행. 실거리 수치는 디버그 대시보드에서만 노출.

폭탄:
- 단일 `Bomb` 클래스 (ObstacleBase 추상화 제거 - 조기 추상화 지적 수용. 2종째 추가 시 추출).
- 근접 트리거(감지 반경 진입) 시 카운트다운 시작. 배치 시점 카운트다운 금지.
- 파라미터: 기폭 시간, 폭발 반경, 감지 반경 (깊이 스케일링 대상).

깊이 스케일링 (`DepthCurve` ScriptableObject 1개):
- 루트 테이블 tier 가중치, 장애물 밀도 + 기폭 시간 감소, 반경 증가.
- 스폰 검증: 좌우 레인 기준 최소 안전 경로 보장 (같은 z구간에 전 레인 봉쇄 금지).

구간 생성:
- `SegmentSpawner` 단일 클래스 뒤로 생성/제거 경계를 캡슐화 (추후 풀링 교체 가능 구조만 확보,
  v0.1은 Instantiate/Destroy).
- 결정적 시드: 런 시작 시 시드 확정, 대시보드 표시, 시드 입력 재현 지원.

스태시 (검증 반영: 가치 합계 -> 아이템 목록):
- `LootDefinition`에 안정 ID(string) 부여.
- 스태시 JSON: { version, entries: [{ itemId, count }] }. 임시파일 작성 후 교체(원자적 저장).

템포 계측:
- 2-3분 라운드 목표를 SegmentDefinition 길이로 데이터화하고,
  대시보드에 구간 소요 시간 표시 (측정 지표 확보).

### 2.4 테스트 (검증 반영, 축소 적용)

- EditMode 테스트만: 정산 규칙, 사망 시 전량 손실, 타이머 랜덤 범위, 스태시 직렬화/복구.
- PlayMode 테스트는 v0.1 범위 외 (수동 플레이 검증으로 대체).

## 3. 트랙 B: 리소스

### 3.1 에셋 목록 (v0.2 대상)

| 에셋 | 수량 | 용도 | 우선순위 |
|------|------|------|----------|

| 골목 소품 (전봇대, 쓰레기봉투, 펜스) | 3-5 | 환경 드레싱 (트랙 C 사용) | 하 |

### 3.2 파이프라인 규약
- 생성: generate_model (meshy-6, glb, 텍스처 포함) 또는 웹+브릿지 수동 생성.
- 정리: `Assets/MeshyImports/` 도착 -> 검수 후 `Assets/Art/Models/<카테고리>/`로 이동, 프리팹화.
- 링크 문서화: `Assets/Art/CLAUDE.md`에 에셋-프리팹-사용처 매핑 기록.
- 스케일/피벗 통일: 임포트 시 1유닛 기준 통일, 프리팹에서 보정.

### 3.3 생성 게이트 (검증 반영)
소품류(폐지, 상자, 폭탄)는 즉시 생성 가능. 단 플레이어 캐릭터는 아래 동결 후 생성:
- 카메라 각도/거리 (쿼터뷰 확정 수치)
- 캐릭터 1유닛 기준 스케일, 피벗(발밑)
- 손수레 분리 여부 (본체와 별도 오브젝트인지, 충돌체 구성)
- 애니메이션 요구 (v0.2는 정적 모델 + 루트 이동만인지, 리깅 필요한지)

### 3.4 교체 작업
- 그레이박스 프리팹의 비주얼 자식만 교체 (로직 프리팹과 비주얼 분리 구조 유지).

## 4. 트랙 C: 환경 및 효과

### 4.1 환경 모듈
- 구간 프리팹용 골목/폐허 환경 모듈: 바닥, 좌우 벽(가벽), 드레싱 소품 슬롯.
- 깊이별 분위기: 깊어질수록 어두워지는 URP Volume 프로파일 3단계.
- 시인성 가드: 최저 조도에서도 루트/폭탄 식별 가능해야 함. v0.1 그레이박스 단계에서
  임시 어두운 프로파일 1개로 선행 확인 (검증 지적: 늦은 시인성 검증 방지).

### 4.2 VFX / 연출
- 폭탄: 카운트다운 점멸 + 폭발 파티클. 최소 예고 시간 규칙 준수 (기폭 시간 하한을 DepthCurve에 명시).
- 루팅: 진행 게이지 + 완료 이펙트.
- 거리 신호: 화면 가장자리 페이드 + 사운드 스팅어 자리 (사운드 소스는 추후).
- 사망: 간단한 슬로우 + 페이드 아웃.

### 4.3 UI 폴리시
- 인벤토리 가치 합계 상시 표시, 선택지 프롬프트, 알림 배너.
- 모바일 세이프 에어리어만 고려, 세부 스킨은 범위 외.
